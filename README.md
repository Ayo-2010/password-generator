# PassForge

Generates strong random passwords in the browser.

## Features

- Uses the Web Crypto API for randomness
- Length control plus character-type options
- Strength meter with crack-time estimate
- Session history and one-click copy

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.

## Files

```
index.html   markup
styles.css   styling
script.js    behaviour
```

## Tech

Plain HTML, CSS and JavaScript.
